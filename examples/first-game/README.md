# Coin Run

A small platformer, written by hand in one JSON file. Two levels, five coins in
each, slimes to squash, spikes to jump and a flag to reach.

```bash
pnpm build
node packages/cli/dist/main.js run examples/first-game
```

Arrow keys or WASD to move, space to jump. Land on a slime to squash it; walk
into one and it costs a life.

## Why this exists

Phase two of the plan is a complete game authored by hand, before any editor is
built. If the format is awkward to write, this is where it shows, and the format
gets fixed rather than papered over by a user interface.

What it found, in order:

- Nothing about the format itself. All eighty rows of both levels validated
  first time, and the shared rules moved into `globalEvents` without trouble.
- Two coins placed higher than a jump reaches. Loading the file cannot catch
  that, so the test suite plays the game and checks every coin sits on
  something.
- A real engine bug: squashing a slime also cost a life, because the squash
  rule's bounce changed what the "walked into an enemy" rule saw. Rules about an
  entity another rule already removed are now skipped.

`assets/` is placeholder art, generated by `tools/make-placeholder-art.mjs`.
Replace it with anything you like: the game only refers to the file names.
